# LifeOS AI – AI-Powered Personal Life Assistant

## About the Project

LifeOS AI is an AI-powered personal life assistant designed to help users manage their daily activities in one place.

## Features

- AI Daily Briefing
- Smart Reminder
- Life Score
- Document Vault
- Expenses & Bills
- Health & Medicine
- AI Assistant

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Ollama

## Project Goal

The goal of LifeOS AI is to make daily life management easier and smarter through a single personal assistant platform.
